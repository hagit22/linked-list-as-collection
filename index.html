בדיקת הקוד של בן/בת הזוג

1

הוספה

הוסיפו 5–6 עצמים, לפחות שניים מאותה קטגוריה. נסו להוסיף עצם שכבר קיים.

playlist.AddSong(song1);   // true
playlist.AddSong(song1);   // false
2

עדכון

עדכנו עצם קיים ועצם שלא קיים. הדפיסו את הערך שחזר.

playlist.PlaySong("Imagine", 4);  // true
playlist.PlaySong("Nope", 4);   // false
3

הסרה

הסירו את הראשון, את האחרון ועצם שלא קיים. אחרי הסרת האחרון הוסיפו עצם חדש. האם הוא נוסף בסוף?

playlist.RemoveSong("Imagine");

עצרו רגע

אתם רואים בעיה בקוד?

השוו את שתי הגרסאות של CountNodes. מה שונה ביניהן?

ואם תיכנס לפרויקט מחלקה שלישית?

פעולה סטטית גנרית

ניתן לזמן עם כל רשימה
// in Main: Console.WriteLine(CountNodes(songs)); Console.WriteLine(CountNodes(cars));
T = כל טיפוס
public static int CountNodes<T>(Node<T> list) { int count = 0; Node<T> current = list; while (current != null) { count++; current = current.GetNext(); } return count; }

פעולה אחת לכל הטיפוסים. ה-<T> אחרי שם הפעולה אומר שהיא עובדת עם טיפוס כלשהו.

עכשיו בפרויקט שלכם

1

CountNodes

מוחקים את שתי הגרסאות וכותבים במקומן פעולה גנרית אחת.

CountNodes<T>(Node<T> list)
2

ItemInPosition

הופכים גם אותה לגנרית. שימו לב: גם הטיפוס שהיא מחזירה משתנה.

ItemInPosition(songs, 2);
ItemInPosition(cars, 2);
3

מריצים ומשווים

הפלט צריך להיות זהה לפלט שהיה לפני השינוי, בשתי הרשימות.

משימת רשות: מערך של אוספים

1

יוצרים מערך

צרו מערך של 3 אוספים מהטיפוס שלכם, והוסיפו לכל אוסף כמה עצמים.

Playlist[] lists = new Playlist[3];
2

כמה בכל אוסף?

עברו על המערך והדפיסו כמה עצמים יש בכל אוסף. השתמשו ב-CountNodes הגנרית.

CountNodes(lists[i].GetSongList())
3

האוסף הגדול ביותר

כתבו פעולה סטטית שמקבלת את המערך ומחזירה את האוסף עם הכי הרבה עצמים.

4

חיפוש

כתבו פעולה סטטית שמקבלת את המערך ושם, ומחזירה את האוסף שבו השם מופיע, או null אם לא נמצא.
